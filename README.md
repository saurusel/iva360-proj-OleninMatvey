# IVA 360 — тестовое задание

Проект воспроизводит шапку, первый экран главной страницы и страницу тарифов сайта
[iva360.ru](https://iva360.ru). Контент управляется через Payload CMS.

## Что реализовано

- шапка с десктопной и мобильной навигацией;
- Hero-слайдер и полоса документов на главной странице;
- страница тарифов с продуктовыми линиями, периодами оплаты и расчётом цены;
- адаптивная вёрстка для десктопа и мобильных устройств;
- управление шапкой, главной страницей и тарифами через CMS;
- русская и английская локали;
- начальные данные CMS и медиа для локального запуска.

## Стек

- Next.js 16, React 19, TypeScript;
- Payload CMS 3;
- MongoDB и MinIO;
- Tailwind CSS;
- UI Kit `@iva360/*`;
- pnpm workspaces и Turborepo.

## Требования

- Node.js `^18.20.2` или `>=20.9.0`;
- pnpm 9 или 10;
- Docker Desktop с Docker Compose.

## Запуск

Из корня проекта:

```bash
pnpm dev
```

При первом запуске команда:

1. создаст `.env` из `.env.example`;
2. установит зависимости;
3. запустит MongoDB и MinIO в Docker;
4. восстановит подготовленные данные и медиа;
5. запустит клиент и CMS.

Если порты `3033`, `3333`, `27027`, `9002` или `9003` уже заняты другим экземпляром
проекта, его нужно остановить перед запуском.

Для корректной работы сессии CMS сайт и админку следует открывать через `127.0.0.1`,
не смешивая этот адрес с `localhost`.

## Адреса

| Сервис        | Адрес                       |
| ------------- | --------------------------- |
| Сайт          | http://127.0.0.1:3033       |
| Админка       | http://127.0.0.1:3333/admin |
| MinIO Console | http://127.0.0.1:9003       |

Доступ в CMS:

```text
Логин: demo@example.ru
Пароль: demo
```

## Страницы и локали

| Страница | Русская версия               | Английская версия |
| -------- | ---------------------------- | ----------------- |
| Главная  | `/` или `/ru`                | `/en`             |
| Тарифы   | `/tariffs` или `/ru/tariffs` | `/en/tariffs`     |

Маршруты без префикса локали отображаются на русском языке.

## Управление контентом

В группе «Контент» админ-панели находятся:

- **Шапка** — топбар, логотип, меню и кнопки;
- **Главная** — слайды Hero, изображения, продуктовые чипы, CTA и полоса документов;
- **Страница тарифов** — заголовок, вкладки, периоды оплаты и блок консультации.

Тарифы редактируются в коллекции **Тарифы**. В CMS задаются данные и разрешённые
варианты отображения, а сетка, типографика и визуальные ограничения остаются на стороне
клиента, чтобы контент-менеджер не мог произвольными настройками сломать вёрстку.

## Полезные команды

```bash
pnpm dev             # полный локальный запуск
pnpm dev:web         # только клиент
pnpm dev:cms         # только CMS
pnpm lint            # ESLint
pnpm typecheck       # проверка TypeScript
pnpm test            # тесты правил CMS
pnpm build           # production-сборка
pnpm generate:types  # обновить типы после изменения схемы Payload
```
